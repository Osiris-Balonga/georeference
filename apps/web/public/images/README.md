# Illustrative artwork

The riverfront, map backdrop and transparent Brazzaville skyline were generated specifically for 242Places and the approved website design. They are illustrations, not documentary photography, surveyed geography or administrative boundaries. The website labels them accordingly. The skyline evokes the Corniche bridge, Nabemba, Sainte-Anne and Mpila towers without claiming measured positions or scale. No third-party photographs are embedded in these files.

Core labels, controls, statistics and relationships are rendered as accessible HTML from the versioned catalog, never baked into an image.
